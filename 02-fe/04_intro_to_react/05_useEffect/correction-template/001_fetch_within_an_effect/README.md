Fetch within an Effect
======================

**Objective:**

Learn how to use the `useEffect` hook in React to handle side effects such as fetching data from an API.

**Instructions:** 

*   Create a simple React component that fetches data from an API and displays it on the screen. Use the \`/todos\` endpoint from:
    *   JSON Placeholder: [https://jsonplaceholder.typicode.com](https://jsonplaceholder.typicode.com/)
*   Use an effect to fetch the data
*   Store data in state
*   Display the todos as list items in an unordered list, and style based on if they are completed
